# 外部字幕與轉錄整合

## KIAO Voice

評估入口：<https://kiao-voice.kiao.com.tw/>。

### 結論

KIAO Voice 適合當「人工審閱前的字幕來源」做小規模試用：支援上傳音訊／影片，輸出 VTT、
SRT、TXT，繁中與中英夾雜是其產品定位的一部分。但它不是本 repo 的可 fork 元件，目前也沒有
可供 pipeline 正式串接的公開 API 證據。

### 資料邊界

- 正式隱私政策：<https://kiao-voice.kiao.com.tw/privacy>。
- 服務條款：<https://kiao-voice.kiao.com.tw/terms>。
- 方案與限制：<https://kiao-voice.kiao.com.tw/pricing>。
- 正式隱私政策載明，批次轉錄音檔與逐字稿預設保留 30 天，並可能由受託第三方技術供應商處理。
- 未經同意不以語音／文字訓練模型，但這不等於資料完全不會離開裝置。
- 首頁「伺服器不保留」是簡化文案；敏感資料治理一律以正式隱私政策為準。
- 條款禁止未經授權的大量自動化存取，因此本 repo 不以逆向或爬蟲方式串接。

### 建議的最小試用流程

1. 只用一段不敏感、可公開、20 分鐘內的測試素材。
2. 下載 SRT；逐句核對人名、品牌、數字、價格與專有名詞。
3. 需要 CapCut 時人工匯入 SRT；需要本 kit gate 時，先轉成明確的 `caps_by_seg` 規格，
   不把 SRT 時碼直接視為畫面與旁白已對齊。
4. 跑交付 QA，尤其是字幕／旁白／B-roll 對位與高風險宣稱證據。
5. 未來若官方提供 API、刪除控制與可驗證的 retention 選項，再評估自動化 adapter。

### 不建議的用途

- 未發布訪談、客戶會議、受 NDA 保護內容或含敏感個資的素材。
- 直接把轉錄結果自動發布，或用 STT 結果生成未經查證的品名、價格與數字字幕。
- 將桌面語音輸入 App 當成本 kit 的批次字幕 API。
